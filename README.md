# ⚡ Asynchronous Task Processing

I use **Celery with Redis** to handle operations that should run independently from the main web request.

```text
                    Django Application
                           │
                           │
                           ▼
                    ┌──────────────┐
                    │    Celery    │
                    │     Tasks    │
                    └──────┬───────┘
                           │
                           │ Task Queue
                           ▼
                    ┌──────────────┐
                    │    Redis     │
                    │ Message Broker│
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │ Celery Worker│
                    │              │
                    │ Background   │
                    │ Processing   │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
         External API   Email/Task   Data Processing
